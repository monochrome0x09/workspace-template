# Completion

TASK.md를 쓴 작업을 완료로 선언하기 전에 따릅니다.

1. TASK.md의 완료 조건을 확인합니다.
2. CHECKLIST.md의 관련 항목을 검증합니다. 점검 결과는 응답에서 보고합니다.
3. 필요한 테스트 또는 사실 검증을 수행합니다.
4. 상태가 실제로 변경되었다면 STATE.md를 갱신합니다.
5. PLAN.md에 해당하는 계획이 완료되었다면 PLAN.md를 갱신합니다.
6. 필요한 결과물이 `outputs/`에 존재하는지 확인합니다.
7. 변경분을 커밋하고 푸시합니다.
8. 완료 조건 확인 뒤, TASK.md를 템플릿 상태로 초기화하는 커밋(`docs/tasks/` 파일을 썼다면 그 파일을 삭제하는 커밋)을 작업 결과 커밋과 분리해 따로 만들어 푸시합니다.

검증하지 못한 항목은 완료로 표시하지 않습니다.
